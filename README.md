# Rollin' Robbers
Rollin’ Robbers is a 2 to 4 player co-op stealth game where you and your crew break into guarded homes, steal high value loot, and escape before you’re caught. Scout layouts, avoid patrols, disable security systems, and grab everything you can carry. One mistake triggers alarms, tightens patrols, and turns a clean job into a desperate escape.
